# Контрольные вопросы для входного и итогового тестирования

Набор из 10 вопросов для оценки усвоения материала при работе с моделью «Учебный Multics».
Все ответы можно проверить в самой модели (команды — в `docs/scenarios.md`).

| № | Вопрос | Эталонный ответ |
|---|---|---|
| 1 | Почему чтение `>sss>kernel_data` из кольца 4 запрещено, хотя ACL даёт право `r`? | Доступ разрешается, только если разрешают и ACL, и кольцевые скобки; скобки 0,0,0 требуют кольцо ≤ 0, а процесс находится в кольце 4 |
| 2 | Какая запись ACL применяется, если подходят несколько? | Наиболее конкретная |
| 3 | Что происходит при первом вызове внешней процедуры? | Linkage fault: поиск сегмента по правилам поиска, проверка доступа, внесение в KST, защёлкивание ссылки |
| 4 | Чем отличается второй вызов той же процедуры? | Ссылка уже защёлкнута, вызов прямой, без linkage fault и поиска |
| 5 | Что даёт шлюз (gate)? | Контролируемый вход в более привилегированное кольцо (4 → 0) и возврат в кольцо вызывающего |
| 6 | В чём различие сегмента и страницы? | Сегмент — логическая единица защиты и совместного использования; страница — единица физического управления памятью |
| 7 | Как работает алгоритм clock и чем он отличается от FIFO? | Страницы просматриваются по кругу, страница со вторым шансом пропускается; FIFO вытесняет самую раннюю загруженную страницу |
| 8 | Почему при выполнении фоновой задачи внутри шлюза команды пользователя идут в кольце 4? | Кольцо хранится отдельно у каждой задачи |
| 9 | Что произойдёт при `set_ring_brackets notes 2 2 2` из кольца 4? | Отказ: нельзя выдать объекту больше привилегий, чем есть у вас |
| 10 | Может ли Petrov, имеющий `r` на `notes`, изменить ACL командой `set_acl ... rew`? | Нет: для изменения ACL нужен режим `m` на каталог, а у Petrov его нет |

## Схема оценки (план)

* Две группы: экспериментальная (сценарии 1–3) и контрольная (те же темы в лекционном формате).
* Входной и итоговый тест по этим вопросам; нормированный прирост g = (итог − вход) / (100 − вход).
* Анкета по шкале Лайкерта (1–5): понятность протокола ядра, полезность сценариев, сложность, вовлечённость.
* Критерии: Манна — Уитни (между группами), Вилкоксона (парные данные), размер эффекта. Участие добровольное, данные анонимные.
